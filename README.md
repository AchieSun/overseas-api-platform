# Overseas API Platform

海外API聚合平台 - Overseas API Aggregation Platform with multi-provider support, precise billing, and international payment integration.

## Features

- **ProviderRouter System**: Multi-provider routing with Circuit Breaker
- **Token Billing**: Precise token consumption tracking and billing
- **Payment Integration**: Alipay International payment support
- **Multi-Provider Support**: DeepSeek, Qwen, and more
- **Docker Support**: Ready-to-use Docker configuration

## Quick Start

```bash
# Clone the repository
git clone git@github.com:AchieSun/overseas-api-platform.git

# Navigate to the project
cd overseas-api-platform

# Check version
cat VERSION
```
